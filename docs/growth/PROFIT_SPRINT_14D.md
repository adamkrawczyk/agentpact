# AgentPact Profitability Sprint (14 Days)

## Objective
Reach a repeatable paid pipeline fast, with strict focus on leading indicators and cash-efficient execution.

**Sprint target (Day 14):**
- 3+ active paid pilots in pipeline
- At least 1 signed pilot or paid setup
- CAC payback path clear (<30 days for pilot-level spend)

## KPI Definitions (single source of truth)
Track daily in `docs/growth/kpi-tracker.csv`.

### Top-line KPIs
- **Leads Added**: New ICP-fit companies added to outreach list.
- **Outreach Sent**: New outbound messages sent (not follow-ups).
- **Positive Replies**: Replies signaling interest, pain, or request for call.
- **Discovery Calls Booked**: Calls scheduled with decision-maker or operator.
- **Calls Completed**: Discovery calls actually held.
- **Proposals Sent**: Paid pilot/proposal docs sent.
- **Pilots Closed**: Signed paid pilots.
- **Revenue Committed (USD)**: Contracted pilot revenue.

### Efficiency KPIs
- **Reply Rate %** = Positive Replies / Outreach Sent
- **Call Booking Rate %** = Discovery Calls Booked / Positive Replies
- **Close Rate %** = Pilots Closed / Proposals Sent
- **Pipeline Value (USD)** = Sum of open proposal values

## Daily Gates (go/no-go)
Use these as decision rules by end-of-day.

1. **Activity Gate**
   - Pass: >=20 new outreach/day
   - Fail: <20 for 2 consecutive days -> reduce scope, improve list quality, simplify messaging.

2. **Message-Market Gate**
   - Pass: Reply Rate >=8%
   - Watch: 5-7%
   - Fail: <5% after 60 sends -> rewrite opener + offer + proof.

3. **Pipeline Gate**
   - Pass: >=1 call booked per 25 sends (rolling)
   - Fail: below threshold for 3 days -> tighten ICP and channel mix.

4. **Monetization Gate**
   - Pass: proposal sent within 24h after each qualified call
   - Fail: any delay >24h -> block new outreach until proposals catch up.

## Offer & Positioning Guardrails
- Lead with one concrete outcome (speed, cost reduction, or revenue lift).
- Start with one narrow ICP at a time (avoid broad vertical spray).
- Pilot terms should be simple: fixed scope, fixed price, 14-30 day window.

## 14-Day Plan

### Days 1-3 (Foundation + Initial Signal)
- Finalize ICP slice + pain statement + offer.
- Build first 100 lead list.
- Send first 60 targeted outreaches.
- Run first call script and objections log.

### Days 4-7 (Optimize Messaging)
- Keep daily outreach cadence.
- A/B test 2 opening hooks and 2 CTA variants.
- Prioritize fastest responding channel.
- Convert calls to paid pilot proposals in <24h.

### Days 8-11 (Push to Closings)
- Follow-up all warm leads with specific next steps.
- Add social proof snippet to all active threads.
- Send deadline-based pilot offers where appropriate.
- Remove low-fit segments from pipeline.

### Days 12-14 (Consolidate + Decision)
- Focus only on highest-conversion segment.
- Drive proposal acceptance and onboarding starts.
- Decide: continue current offer, reprice, or pivot ICP.
- Produce short sprint retrospective with KPI deltas.

## Day 1 Execution Checklist (Practical Minimum)
- [ ] Define single ICP and one painful workflow to automate.
- [ ] Add 30 qualified leads.
- [ ] Send 20 personalized outreaches using template v1.
- [ ] Track metrics in CSV before end of day.
- [ ] Book at least 1 discovery call target for next 72h.

## Daily Standup Questions
- What did we send yesterday?
- Where did replies come from?
- What blocked proposals or calls?
- What gets removed today to keep speed high?
