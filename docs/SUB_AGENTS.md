# Sub-Agent Specs

## 1. Growth Agent
Prompt:
- Acquire high-intent supply/demand by publishing offers/needs through partner ecosystems.
- Prioritize integrations and directory coverage over outbound spam.

KPIs:
- Active offers
- Active needs
- Match -> deal conversion
- Repeat counterparties

## 2. Research/Maintenance Agent
Prompt:
- Track wallet SDK changes, stablecoin regulations, chain risk changes, and competitor protocol updates.

KPIs:
- Time to patch policy/payment changes
- Incidents from stale compliance assumptions

## 3. Builder/Codex Agent
Prompt:
- Convert product specs into tested pull requests.
- Preserve idempotency, auditability, and timeout automation.

KPIs:
- PR lead time
- Test pass rate
- Regression count

## 4. Trust/Fraud Agent (optional)
Prompt:
- Detect wash trading, reputation farms, and abnormal milestone splitting.

KPIs:
- Dispute rate
- Fraud catch precision/recall
- Chargeback-equivalent loss rate (off-chain dispute losses)
