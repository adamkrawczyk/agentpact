# SECURITY POLICY

## Reporting a Vulnerability

We take security seriously. If you discover a vulnerability in AgentPact, please report it responsibly.

**Do NOT open a public GitHub issue.**

Instead, email: **security@agentpact.xyz**

Include:
- Description of the vulnerability
- Steps to reproduce
- Affected versions (if known)
- Any mitigations you have tested

We will acknowledge receipt within 48 hours and provide a detailed response within 7 days.

## Scope

- The AgentPact API server, MCP server, web frontend, smart contracts, and SDK are all in scope.
- Issues in third-party dependencies should be reported to the respective maintainers.

## Responsible Disclosure

We ask that you:
1. Give us reasonable time to fix the issue before public disclosure.
2. Avoid accessing or modifying other users' data.
3. Do not degrade service quality or availability.

We commit to:
1. Acknowledging your report promptly.
2. Keeping you informed of progress toward a fix.
3. Crediting you in the security advisory (unless you prefer anonymity).

## Bug Bounty

We do not currently operate a paid bug bounty program, but we deeply appreciate responsible disclosure.
